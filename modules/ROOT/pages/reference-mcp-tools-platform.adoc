= MuleSoft Platform MCP Server Tool Reference

MuleSoft Platform MCP Server exposes tools for managing APIs, agents, LLMs, MCP servers, governance strategies, policies, gateways, observability, and cost optimization across Anypoint Platform. Each tool accepts specific input parameters so assistants can search the portfolio, inspect resources, and apply changes on your behalf. Use these tools from your IDE or another MCP client to automate platform administration and surface operational insight.

See xref:getting-started-platform.adoc[Get Started with MuleSoft Platform MCP Server] for setup and authentication, including the Connected App scopes that map to each permission tier.

[[fetch-cost-instances]]
== fetch_cost_instances

Get per-instance token usage and optimization coverage across MCP servers and agents. To optimize an MCP instance, pass its `unappliedCostPolicyIds` to `prepare_policy_creation`.

[%header,cols="1,3,1"]
|===
|Parameter |Description |Required

|`category`
|Scope of the query. Defaults to `mcp`. Supported values: `mcp` returns per-MCP-server-instance token usage with optimization coverage (includes `totalTokens`, `tokenDelta`, `avgResponseTimeMs`, `toolsListTokens`, `toolsCallTokens`, `appliedCostPolicyIds`, `unappliedCostPolicyIds`, and `optimizationCoverage`). `agent` returns per-agent LLM-proxy spend and savings in dollars (not token estimates). Dollar figures depend on cost data being available for the org (the response carries `costDataAvailable`). When `false`, spend and saved are zeroed placeholders. `filter_unoptimized` and `sort_by` do not apply to the agent scope.
|No

|`filter_unoptimized`
|Set to `true` to return only instances that have unapplied cost policies (`unappliedCostPolicyIds` not empty). Use this to find optimization candidates quickly. Defaults to `false`. Applies to `mcp` category only.
|No

|`organization_id`
|Organization ID to query for per-instance usage and optimization coverage.
|Yes

|`sort_by`
|Sort field for results. Supported values: `totalTokens`, `tokenDelta`, `avgResponseTimeMs`, `totalCalls`, `tokensPerCall`. Defaults to `totalTokens`. Applies to `mcp` category only.
|No

|`time_range`
|Time window for usage analysis. Supported values: `1h`, `6h`, `24h`, `7d`, `30d`. Defaults to `30d`.
|No

|`top_n`
|Maximum number of instances to return. Defaults to `10`; maximum is `50`.
|No

|===

.Example request
[source,json]
----
{
  "name": "fetch_cost_instances",
  "arguments": {
    "organization_id": "<organization_id>"
  }
}
----

.Example response
[source,json]
----
{
  "instances": [
    {
      "instanceId": "16834521",

      "totalTokens": 4218903,
      "tokenDelta": 612418,
      "avgResponseTimeMs": 287,
      "totalCalls": 5142,
      "tokensPerCall": 820,
      "toolsListTokens": 1402189,
      "toolsCallTokens": 2816714,
      "appliedPolicies": ["client-id-enforcement"],
      "appliedCostPolicyIds": [],
      "unappliedCostPolicyIds": ["tool-output-truncation", "response-caching"],
      "optimizationCoverage": 0.0
    }
