= Getting Started with MuleSoft Platform MCP Server

Scan, discover, govern, and monitor APIs, agents, MCP servers, and LLMs across your entire IT landscape from a single AI-accessible interface. MuleSoft Platform MCP Server gives AI tools governed access to your infrastructure to accelerate production-ready AI deployment. Connect your IDE in minutes using any MCP-compatible client.

== Create a Connected App

Follow the steps in xref:access-management::creating-connected-apps-dev.adoc#create-connected-app[Create a Connected App That Acts on the User’s Behalf] to create a connected app.

Additionally, when prompted, add the following permission scopes. These scopes enable you to use specific MuleSoft MCP Server tools. Make sure that all business groups and relevant environments are selected for these scopes.

IMPORTANT: When creating the connected app, be sure to select the Authorization Code and Refresh Token grant types. 

Refer to the xref:reference-mcp-tools-platform.adoc[MuleSoft Platform MCP Server Tool Reference] for details on all MuleSoft Platform MCP Server tools. Only tools listed in these tables require specific permission scopes.

== Configure Your IDE

Configure Claude Desktop, Cursor, Windsurf, Zed, or other IDEs to work with MuleSoft Platform MCP Server. After you add the configuration, verify it by checking that the server has started in the MCP section of your IDE.

=== Available Client Connections

When configuring your AI tool, use the endpoint for your region.

Use `/mcp`, and fall back to `/mcp/sse` if the client does not connect.

=== Claude Desktop

In Claude Desktop:

1. Click **Customize** > **Connectors**.
2. Click the add (**+**) icon, and then click **Add Custom Connector**.
3. Add a name for the connection, and in the **Remote Universal URL** field, add the appropriate URL, for example `https://omni.mulesoft.com/mcp`.

Or run this command in your terminal:

`claude mcp add --transport http mulesoft-platform <URL for your region>`

Download https://claude.com/download[Claude Desktop].

=== Cursor

In Cursor:

1. Click **Settings** -> **Tools and MCPs** -> **Add a Custom MCP Server**.
2. Add the following code snippet:

----
{
  "mcpServers": {
    "mulesoft-platform": {
      "url": "<URL for your region, for example https://omni.mulesoft.com/mcp>",
      "auth": {
        "CLIENT_ID": "your-client-id",
        "CLIENT_SECRET": "your-client-secret"
      }
    }
  }
}
----

Download https://cursor.com/[Cursor].

=== Windsurf

In Windsurf:

1. Click **Settings** > **Cascade** > **Open MCP Registry**.
2. Click the settings icon and in `~/.codeium/windsurf/mcp_config.json` add the following code snippet:

----
{
  "mcpServers": {
    "mulesoft-platform": {
      "url": "<URL for your region, for example https://omni.mulesoft.com/mcp>",
      "headers": {
        "CLIENT_ID": "your-client-id",
        "CLIENT_SECRET": "your-client-secret"
      }
    }
  }
}
----

Download https://windsurf.com/[Windsurf].

=== Cline

In Cline:

1. Click the MCP Servers icon, and select the **Remote Servers** tab.
2. Add a name for the connection, and in the **Remote Universal URL** field, add the appropriate URL, for example `https://omni.mulesoft.com/mcp`.
3. When prompted, authenticate your connection.

Download https://cline.bot/[Cline].

=== VS Code

In VS Code:

In your user profile, configure a custom MCP server in the `mcp.json` file.

----
{
  "servers": {
    "mulesoft-platform": {
      "url": "<URL for your region, for example https://omni.mulesoft.com/mcp>",
      "headers": {
        "CLIENT_ID": "your-client-id",
        "CLIENT_SECRET": "your-client-secret"
      }
    }
  }
}
----

Alternatively, run `MCP: Add Server` in the Command Palette (⇧⌘P) to add a server through a guided flow.

Download https://code.visualstudio.com/[VS Code].
