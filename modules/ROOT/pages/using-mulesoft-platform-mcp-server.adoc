= Using MuleSoft Platform MCP Server

MuleSoft Platform MCP Server provides governed access to your entire agentic landscape, including APIs, agents, MCP servers, and LLMs, to accelerate production-ready AI at scale. It helps you scan, discover, govern, and monitor services across the infrastructure you already run.

To learn more about how to set up MuleSoft Platform MCP Server, see xref:getting-started-platform.adoc[].

To learn more about MuleSoft Platform MCP Server tools, see xref:reference-mcp-tools-platform.adoc[].

== Before You Begin

Before you get started, make sure you complete the setup and configuration steps, including permissions, in xref:getting-started-platform.adoc[].

== Example: Search Assets Across MuleSoft Platform

. In your MCP-compatible IDE, open the agent panel.
. Sign in. MuleSoft Platform MCP Server requires authentication through the `login` tool before using other tools.
. In the prompt field, ask the agent to search for assets in your organization.

For example, use this prompt: `Show me all payment-related APIs across my organization.`

For global search, the agent uses `search_global_assets`, which requires both `query` and `business_group_id`.

[source,json]
----
{
  "query": "payment-related APIs",
  "business_group_id": "<business_group_id>",
  "size": 20
}
----

The `search_global_assets` tool searches for agents, MCP servers, and APIs. It returns ranked results.

== Example Prompts

Use prompts like these to explore key platform workflows:

* Search and browse: `Show me all payment-related APIs across my organization.`
* Govern and secure: `Create a governance strategy that applies a PII detection policy to all customer-facing agents.`
* Monitor and analyze: `Which LLMs consumed the most requests last week?`
